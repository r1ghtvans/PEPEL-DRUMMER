ШРИФТЫ / FONTS
Плагин использует три файла шрифтов. Чтобы поставить свои, просто замените файлы
с теми же именами и пересоберите (коммит на GitHub запустит сборку):

  FontTitle.ttf   заголовок и названия панелей (сейчас: Press Start 2P)
  FontText.ttf    основной текст и значения (сейчас: VT323)
  FontKanji.ttf   иероглифы 灰愛 вверху справа (сейчас: DotGothic16, только эти 2 знака)

Для FontKanji нужен шрифт с иероглифами (CJK). Подпись "by ПЕПЕL" использует FontTitle,
поэтому в нём должна быть кириллица.
Тексты лицензий OFL лежат в папке licenses/.
